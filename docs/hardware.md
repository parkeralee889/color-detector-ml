I used Fusion 360 to design my model.
I sliced my model on Bambu Studio and 3d printed my model using a Bambu Lab P2S.
My model consist of two models:
A bottom model which will hold the different colored pieces of paper.
A top model which also has the legs on it that holds it high over the bottom piece. This part will hold the webcam which it is around 250mm tall because the webcam doesn't have autofocus.
The webcam that I am using is the Logitech Brio 100, which I found lying around my house that I think my dad used to use.

Top Model: my first itteration had a few problems. First, the front legs on it were very fragile. Second, the tree support that I printed with was extremely hard to get off. I fixed the problem with the front legs by having them connect to the back legs halfway through. I fixed the tree supports by using the manual tree supports feature on Bambu Studio.
